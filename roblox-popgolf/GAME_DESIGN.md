# ⛳ 팝골프 (Pop Golf) — 기획서 v2 (2대2 팀 배틀 골프)

## 1. 한 줄 소개
캐릭터가 직접 코스를 뛰어다니며 골프채로 **팀 공**을 치고, 상대 선수를 골프채로 넘어뜨리거나 상대 공을 쳐 내면서 **먼저 홀컵에 넣는 팀이 이기는** 2대2 배틀 골프.

## 2. 저작권 원칙
- 게임 **규칙·방식**(캐릭터가 뛰어다니며 치는 배틀 골프)은 저작권 보호 대상이 아니라 장르로 자유롭게 쓸 수 있음
- 대신 **표현물은 전부 새로 만듦**: 게임 이름, 캐릭터(로블록스 기본 아바타 사용), 코스(코드로 매번 새로 생성), 아이템 이름·효과(물풍선, 돌풍 등), UI, 이미지, 소리
- 다른 게임의 이름·로고·스크린샷·음악·맵 모양을 **설명·썸네일·광고에 쓰지 않음** ("○○ 같은 게임" 같은 문구도 금지)
- 차별화 포인트: **2대2 팀이 공 하나를 공유**하는 규칙 → "공 치는 사람 + 지키는 사람" 역할 분담

## 3. 타깃 연령층
- **핵심: 10~16세**, 친구 2~4명이 같이 들어오는 유저 (팀전이라 친구 초대 동기가 강함)
- 넘어뜨리기는 만화 같은 날아가기·일어나기 연출만 (피·부상 없음) → 성숙도 질문지에서 "폭력"은 **가벼운/비현실적** 수준으로 답할 것 (6장)

## 4. 규칙
| 항목 | 내용 |
|---|---|
| 팀 | 🔴 레드 vs 🔵 블루, 무작위 배정. 인원에 맞춰 자동: 4명 2대2 · 6명 3대3 · 8명 4대4 (홀수면 한 명 차이, 1명은 연습). 인원이 많을수록 페어웨이 폭 +6/명, 아이템 상자 +2/명 |
| 공 | 팀마다 하나 (팀 색깔). **타수 없음** |
| 휘두르기 (유일한 공격 버튼) | 꾹 누르면 골프채가 뒤로 올라가며 힘이 모이고(게이지 0→100→0 왕복), 떼면 휘두름. 몸 앞 6.5스터드 안의 **모든 공(우리 공·상대 공)** 은 카메라 방향으로 날아가고, **상대 선수**는 날아가 1.6초 넘어짐 |
| 공의 비행 | 페어웨이·러프에서는 36° 로 높이 떠서 포물선 비행, 그린 위에서는 4° 로 굴리는 퍼팅(세기 38%) |
| 바닥 | 페어웨이(잘 구름) · 그린(아주 잘 구름) · 러프(덜 구름) · 벙커(거의 안 구름) · 연못(빠지면 마지막 멈춘 자리로) · 나무(튕김) |
| 홀 승리 | **자기 팀 공**을 먼저 홀컵에 넣은 팀 (상대가 실수로 넣어 줘도 인정). 180초가 지나면 홀컵에 더 가까운 팀 |
| 경기 | 홀 3개 → 이긴 홀이 많은 팀 우승, 같으면 무승부 |
| 아이템 (❓ 상자, 무료) | 💣 물풍선 폭탄 · 🧊 얼음(상대 공 5초 정지) · 👟 대시 신발 · 🛡️ 방패 · 🌬️ 돌풍 |

### 전투 키트 (모두 무료 · 모두 같은 성능)
| 키 | 능력 | 효과 | 쿨다운 |
|---|---|---|---|
| Q | 💨 대시 | 순간 돌진(공중이면 1.25배), 직후 0.3초 회피 | 2.2초 |
| E | ⚡ 스킬 (로비에서 1개 선택) | 💥 돌진 태클 · 🧲 볼 리콜 · 🫧 버블 쉴드(반사) · ❄️ 서리 지대 · ⚡ 파워 드라이브 | 10~15초 |
| R | ☄️ 메테오 스윙 | 게이지(공 치기 +12, 넘어뜨리기 +20, 1초 +1) 100 → 다음 스윙이 반경 12 전부 날림 | 게이지 |
| F | ❓ 아이템 | 💣 물풍선 · 🧊 얼음 · 🌬️ 돌풍 (코스 상자, 2대2 기준 4개) | 1회용 |

- 넘어짐 시간 1.6 → 1.2초 (대시 회피가 생겨서 템포를 빠르게)
- **스킬·능력은 판매하지 않음**: 팀 대전 게임에서 능력을 뽑기로 팔면 '돈 쓰면 이기는 게임'이 됨. 매출은 꾸미기(골프채 스킨)로만

### 그래픽 (네온 e스포츠 아레나 컨셉)
- **로비:** 실내 네온 아레나 홀 — 빛나는 격자 바닥, 청록·분홍 네온 벽, 천장 조명 패널, 대형 전광판 3개(전체 승리 순위·이 서버 MVP·넘어뜨림 왕, OrderedDataStore), 1·2·3 시상대, 빛나는 캡슐 포스터·캡슐 머신, 회전하는 골프채 전시대, 스킬·상점 키오스크
- **PLAY 대기열:** PLAY 를 누른 사람만 경기에 들어감 (로비에서 구경·뽑기 가능)
- **일일 미션:** 경기 3판(🪙150) · 공 15번 치기(🪙100 💎5) · 1승(🪙200 💎10)
- **경기장:** 페어웨이 네온 테두리, 조명탑 6개(스포트라이트), LED 전광판 2개, 관중석. 마지막 홀은 '네온 나이트'
- **UI:** 레드|타이머|블루 점수판, 원형 능력 버튼 + 키 표시 + 이름, 기울어진 궁극기 게이지, 재화 알약, 로비 아래 메뉴 줄 + 큰 PLAY 버튼, 아이콘 그림(images/icons)
- **이펙트:** 타격마다 고리·빛 파편·반짝임, 메테오/강타는 에너지 기둥·고리 3겹·보라 불꽃·화면 흔들림
- **코스:** 러프=지형 잔디(풀잎 장식), 벙커=지형 모래, 연못=진짜 물(파고 채움), 바깥 언덕·바위, 여러 겹 잎 나무·덤불·꽃·카트 길
- **캐릭터:** 경기 중 팀 색 골프 모자 + 팀 색 외곽선
- 조명: 밝기·노출 보정, 대기(Atmosphere), 빛 번짐(Bloom), 색 보정(채도 +18%, 대비 +10%), 햇살, 구름
- 전투 연출: 대시 잔상, 맞히면 화면 살짝 흔들림, 맞으면 크게 흔들림 + 붉은 번쩍임, 팀 색 외곽선, 파워 드라이브 반짝임, 궁극기 불꽃 오라, 메테오 충격파

### 코스
- 매 홀 새로 생성: 티 → 좌우로 휘는 260~380스터드 페어웨이(줄무늬 잔디) → 반지름 26 그린, 깃발(멀리서도 ⛳ 표시)
- 벙커 2~4개(그린 옆 1개 고정), 연못 0~2개, 나무 40그루, 아이템 상자 6개

### 모션
- 골프채는 몸통 관절에 붙어 있고, 각 화면에서 **골프채 + 양팔 + 허리**를 함께 돌려 백스윙 → 내려치기 → 팔로스루를 재생
- 힘을 모을수록 골프채가 높이 올라가서 상대도 '얼마나 세게 칠지' 눈으로 보고 피할 수 있음
