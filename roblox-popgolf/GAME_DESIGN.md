# ⛳ 펑! 골프 파티 (Pop Golf Party) — 기획서 v2 (2대2 팀 배틀 골프)

## 1. 한 줄 소개
캐릭터가 직접 코스를 뛰어다니며 골프채로 **팀 공**을 치고, 상대 선수를 골프채로 넘어뜨리거나 상대 공을 쳐 내면서 **먼저 홀컵에 넣는 팀이 이기는** 2대2 배틀 골프.

## 2. 저작권 원칙
- 게임 **규칙·방식**(캐릭터가 뛰어다니며 치는 배틀 골프)은 저작권 보호 대상이 아니라 장르로 자유롭게 쓸 수 있음
- 대신 **표현물은 전부 새로 만듦**: 게임 이름, 캐릭터(로블록스 기본 아바타 사용), 코스(코드로 매번 새로 생성), 아이템 이름·효과(물풍선, 돌풍 등), UI, 이미지, 소리
- 다른 게임의 이름·로고·스크린샷·음악·맵 모양을 **설명·썸네일·광고에 쓰지 않음** ("○○ 같은 게임" 같은 문구도 금지)
- 차별화 포인트: **2대2 팀이 공 하나를 공유**하는 규칙 → "공 치는 사람 + 지키는 사람" 역할 분담

## 3. 타깃 연령층
- **핵심: 10~16세**, 친구 2~4명이 같이 들어오는 유저 (팀전이라 친구 초대 동기가 강함)
- 넘어뜨리기는 만화 같은 날아가기·일어나기 연출만 (피·부상 없음) → 성숙도 질문지에서 "폭력"은 **가벼운/비현실적** 수준으로 답할 것 (6장)

## 4. 규칙
| 항목 | 내용 |
|---|---|
| 팀 | 🔴 레드 vs 🔵 블루, 무작위 배정 (4명 2대2, 3명 2대1, 2명 1대1, 1명 연습) |
| 공 | 팀마다 하나 (팀 색깔). 팀원 누구든 공 옆 7스터드 안에서 샷 가능 |
| 샷 | 마우스 왼쪽 꾹 → 떼기. 파워 게이지 0→100→0 왕복. 카메라 방향으로 날아감 |
| 휘두르기 | 공에서 떨어져 클릭(또는 F): 앞 8스터드 안 상대 선수 **1.6초 넘어짐**, 상대 공은 **쳐 내짐**(상대 타수는 안 늘어남) |
| 홀 승리 | **먼저 홀컵에 넣은 팀**. 150초가 지나면 홀컵에 더 가까운 팀 |
| 경기 | 홀 3개 → 이긴 홀이 많은 팀 우승, 같으면 총 타수가 적은 팀 |
| 아이템 (❓ 상자, 무료) | 💣 물풍선 폭탄 · 🧊 얼음(상대 공 5초 정지) · 👟 대시 신발 · 🛡️ 방패(8초 안 넘어짐) · 🌬️ 돌풍(상대 전원 날림) |
| 장외 | 공이 코스 밖으로 떨어지면 마지막 친 자리 + 벌타 1, 선수는 팀 공 옆으로 복귀 |

## 5. 수익 모델 (가챠 포함)
- **꾸미기 = 골프채 스킨 21종**. 팀 공은 팀 색으로 고정해서 판단을 헷갈리게 하지 않음
- 등급이 오를수록 연출이 눈에 띄게 화려해짐 (다른 사람에게 보여서 '갖고 싶게' 만드는 것이 꾸미기 매출의 핵심)

| 등급 | 평소 모습 | 휘두를 때 |
|---|---|---|
| 일반 | 색·재질 + 빛 꼬리 | 작은 반짝임 |
| 희귀 | + 은은한 빛 입자 | 반짝임 |
| 영웅 | + 보석, 빛구슬 2개 회전, 숨 쉬는 빛 | + 충격파 고리 |
| 전설 | + 금테, 빛구슬 3개, 회전 고리 | 큰 폭발 + 내 화면 펀치 |
| 신화 | + 빛구슬 4개, **무지개색 변화** | 최대 폭발 |

- 메뉴에서는 3D 골프채가 빙글빙글 돌고, 영웅 이상 카드는 테두리가 반짝이며 돎. 전설 이상을 뽑으면 화면이 번쩍
- 연출은 각자 화면에서 그려서(ClubFX) 서버 부담 0. 스킨별 세부 조정은 `Config.Skins` 의 `fx` 로
- 재화: 🪙 코인(경기로만, **판매 안 함**) · 💎 젬(경기 소량 + 로벅스) · 🧩 조각(중복 분해)
- 캡슐: 🟢 일반(🪙300) / 💎 프리미엄(💎50, 10연차 💎450)
- 안전장치: 확률·스킨별 확률 공개, 10연차 영웅 이상 보장, 50회 전설 천장, 조각으로 직접 구매, 확률형 제한 지역 차단, 게임패스는 확률형 아이템 미지급
- 상품: 🎁 스타터 팩 99 R$ (💎300 + 희귀 골프채) · 💎 110/500/1300 = 49/199/449 R$ · 👑 VIP 299 R$ · 🎯 정밀 조준 149 R$
- **팀전 특화 수익 포인트**: 비공개 서버(친구 4명 전용 방) 판매를 켜 두세요 — 2대2 게임과 궁합이 가장 좋음
