# ⛳ 펑! 골프 파티 (Pop Golf Party) — 기획서

## 1. 한 줄 소개
최대 8명이 **동시에** 같은 홀을 치는 배틀 미니골프. ❓ 상자에서 폭탄·얼음·회오리를 얻어 남의 공을 날려 버리고 먼저 홀컵에 넣자!

> 특정 게임을 베낀 것이 아니라 "멀티플레이 배틀 골프" 장르로 새로 만든 게임입니다. 이름·코스·아이템·디자인 모두 독자적입니다.

## 2. 왜 이 장르인가
| 근거 | 설명 |
|---|---|
| 순서 기다림 없음 | 일반 골프는 내 차례를 기다려야 하지만, 여기선 **모두 동시에** 쳐서 지루할 틈이 없음 |
| 친구와 웃기는 순간 | 홀컵 바로 앞에서 폭탄 맞고 날아가는 장면 → 스트리머·쇼츠 소재 |
| 매 홀 새 코스 | 코스를 코드가 매번 새로 만듦 (꼬불길, 범퍼, 회전 막대, 가속 발판) |
| 짧은 판 | 홀당 최대 2분 × 3홀 ≈ 6~7분 한 판 |

## 3. 타깃 연령층
- **핵심: 9~15세**, 친구 2~4명이 함께 들어오는 유저.
- 폭력·피 없음 (폭탄은 공을 밀어내는 만화 연출만) → 성숙도 **최소(Minimal)** 목표.
- **가챠가 있으므로** 아래 5장의 안전장치를 반드시 유지하세요.

## 4. 게임 규칙
1. 로비에서 20초 대기 → 경기 시작 (혼자서도 연습 가능)
2. 홀 3개. 카메라 방향으로 조준하고, 마우스 왼쪽(모바일은 ⛳ 버튼)을 **꾹 눌렀다 떼면** 샷. 파워 게이지는 0→100→0 으로 왕복
3. 공이 멈춰야 다음 샷. 장외는 벌타 +1, 12타 넘으면 그 홀은 기권
4. 홀인 순서대로 10·8·6·5·4·3·2·1점. 3홀 합계 1등이 우승
5. ❓ 상자(무료): 💣 폭탄 · 🧊 얼음 · ⚡ 슈퍼샷 · 🧲 자석 · 🌀 회오리 — **돈으로 살 수 없음** (공정성)

## 5. 수익 모델 (가챠 포함)
### 재화 3종
| 재화 | 얻는 법 | 쓰는 곳 |
|---|---|---|
| 🪙 코인 | **경기로만** (판매 안 함) | 일반 캡슐 |
| 💎 젬 | 매일 첫 경기 +20, 우승 +5, 홀인원 +5, **로벅스 구매** | 프리미엄 캡슐 |
| 🧩 조각 | 중복 스킨 분해 | 원하는 스킨 **직접 구매** |

### 캡슐 (가챠) — 공 꾸미기 21종
| 캡슐 | 가격 | 확률 |
|---|---|---|
| 🟢 일반 | 🪙 300 | 일반 70% · 희귀 25% · 영웅 5% |
| 💎 프리미엄 | 💎 50 / 10연차 💎 450 | 희귀 60% · 영웅 30% · 전설 9% · 신화 1% |

**안전장치 (로블록스 정책 + 한국 확률 공개 의무 대응)**
- 🎨 **꾸미기 전용**: 스킨은 공 색·재질·꼬리 효과만 바꿈. 성능 차이 0
- 📊 **확률 공개**: 등급별 확률 + 스킨 하나하나의 확률을 뽑기 화면에 항상 표시
- 🛟 **천장**: 10연차는 영웅 이상 1개 보장, 프리미엄 50회 안에 전설 이상 확정 (남은 횟수 표시)
- 🧩 **조각 상점**: 중복은 조각으로 바뀌고, 조각으로 원하는 스킨을 확률 없이 구매 → "끝없이 뽑아야 하는" 구조 방지
- 🌍 **지역 제한**: 확률형 아이템이 금지된 나라(PolicyService)에서는 프리미엄 캡슐과 젬 판매를 숨김. 정보를 못 받으면 안전하게 '제한'으로 처리
- 🪙 **코인은 절대 판매하지 않음**: 코인을 돈으로 살 수 있으면 일반 캡슐도 유료 확률형이 됨. 그래서 '코인 2배' 패스·코인 상품을 일부러 넣지 않음
- 👑 게임패스(VIP)는 확률형 아이템을 주지 않음 (정책) → VIP 전용 왕관 공은 뽑기 밖의 확정 보상

## 6. 성숙도 질문지
- 폭력: 없음 (공을 밀어내는 연출만)
- **유료 확률형 아이템: 예** (프리미엄 캡슐) — 확률 공개 완료
- 도박: 아니오 (실제 돈/로벅스를 걸고 따는 게임 아님)
