# 게임 페이지 설명 (복사해서 붙여넣기)

크리에이터 허브 → 내 게임 → 기본 정보에서 이름과 설명 칸에 붙여넣으세요. 영어는 **현지화**(Localization)에서 영어 번역으로 등록하세요.

⚠️ 다른 게임 이름(예: "○○ 골프 같은 게임")은 설명·태그·광고에 넣지 마세요. 상표 문제와 로블록스 신고 대상이 될 수 있어요.

## 🇰🇷 한국어

**이름:** ⛳ 펑! 골프 파티 [2대2 팀 배틀 골프]

**설명:**
```
⛳ 2대2 팀 배틀 골프! 우리 공을 먼저 홀컵에 넣는 팀이 이겨요!

🔴 레드 팀 vs 🔵 블루 팀 — 팀마다 공이 하나, 타수는 없어요!
🏌️ 꾹 눌러 힘을 모았다가 휘두르면 앞에 있는 건 전부 맞아요
• 공은 하늘 높이 날아가고
• 상대 선수는 날아가 넘어지고
• 상대 팀 공도 멀리 쳐 낼 수 있어요!

⛳ 진짜 골프장 같은 코스
• 굽이치는 페어웨이, 그린, 벙커, 연못, 나무
• 매 홀 새로운 코스

❓ 아이템 상자: 💣 물풍선 · 🧊 얼음 · 👟 대시 · 🛡️ 방패 · 🌬️ 돌풍

🎨 골프채 꾸미기 21종 — 빛 입자·고리·무지개 연출 (확률은 게임 안에 공개, 성능 차이 없음)

👫 친구와 팀을 짜서 뒤엉켜 보세요!
👍 재밌었다면 좋아요와 즐겨찾기 부탁해요!
```
