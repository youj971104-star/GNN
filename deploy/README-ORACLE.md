# 오라클 클라우드 무료 VM 에 설치하기

월 비용 **0원**으로 인터넷 어디서든 접속 가능한 서버를 만듭니다.
오라클이 제공하는 "Always Free" 서버를 씁니다.

전체 소요 시간은 **30~40분** 정도이고, 대부분은 오라클 계정 만들기와 승인 대기입니다.

---

## 먼저 알아두실 것

| 항목 | 내용 |
| --- | --- |
| 비용 | 0원. 단, 계정 만들 때 **신용카드 등록이 필요**합니다(본인 확인용, 청구되지 않음) |
| 사양 | ARM 2코어 / 메모리 12GB / 디스크 200GB — 이 프로그램에는 차고 넘칩니다 |
| 주의 ① | 7일간 거의 안 쓰면 오라클이 서버를 회수해 갑니다 → **아래 4단계에서 해결** |
| 주의 ② | 자산 데이터가 인터넷에 열린 서버에 올라갑니다. 사내 보안 정책을 먼저 확인하세요 |

> **보안 참고** — 이 시스템은 로그인해야만 자료를 볼 수 있고 비밀번호는 암호화해 저장합니다.
> 다만 주소만 알면 누구나 로그인 화면까지는 닿습니다. 관리자 비밀번호를 반드시 바꾸시고,
> 가능하면 나중에 도메인 + HTTPS 까지 붙이시길 권합니다([README-HTTPS.md](README-HTTPS.md)).

---

## 1단계 · 오라클 클라우드 계정 만들기

1. <https://www.oracle.com/kr/cloud/free/> 접속 → **무료로 시작하기**
2. 이메일, 국가(대한민국), 이름 입력 후 이메일 인증
3. **홈 리전은 반드시 `South Korea Central (Seoul)` 또는 `Japan East (Tokyo)`** 로 고르세요.
   한 번 정하면 못 바꾸고, 멀면 접속이 느려집니다.
4. 신용카드 등록 (본인 확인용으로 약 1달러가 잠시 잡혔다 풀립니다)
5. 가입 완료까지 보통 5~15분 걸립니다

## 2단계 · 서버(VM) 만들기

콘솔에서 **컴퓨트 → 인스턴스 → 인스턴스 생성**

| 설정 | 선택할 값 |
| --- | --- |
| 이름 | `itam-server` (아무 이름이나 괜찮습니다) |
| 이미지 | **Canonical Ubuntu 24.04** |
| shape | **Ampere → VM.Standard.A1.Flex** (기본값 그대로 두면 됩니다) |
| 네트워킹 | 기본값 그대로 (공용 IPv4 주소 **할당** 체크 확인) |
| SSH 키 | **개인 키 저장**을 눌러 키 파일을 내려받아 두세요 (접속에 꼭 필요합니다) |

### shape 화면에서 확인할 것

shape 목록에 **`VM.Standard.A1.Flex` 하나만** 나오는 게 정상입니다.
Ampere 시리즈에는 이 shape 하나뿐입니다. 이름 옆에 **`Always Free-eligible`** 배지가
붙어 있는지만 확인하세요. 그 배지가 있으면 과금되지 않습니다.

기본값은 보통 **OCPU 1 / 메모리 6GB** 로 나옵니다. **이 프로그램에는 그대로도 충분합니다**
(평소 메모리 500MB 미만을 씁니다). 무료 한도는 2 OCPU / 12GB 까지라 늘려도 0원이며,
늘리려면 shape 이름 왼쪽의 `▸` 를 펼치면 조절 항목이 나옵니다.

> **작게 요청하는 편이 유리합니다.** ARM 무료 서버는 인기가 많아
> **"용량 부족(Out of capacity)"** 오류가 자주 납니다. 요청 사양이 작을수록 잡힐 확률이 높으니
> 기본값(1 OCPU / 6GB)으로 진행하시길 권합니다. 사양은 나중에 올릴 수 있습니다.
>
> 그래도 용량 부족이 나면, 몇 시간 뒤 다시 시도하거나
> 다른 가용성 도메인(AD-1/2/3)을 바꿔가며 시도해 보세요.

### 나머지 단계는 모두 기본값

생성 화면에는 **보안(Security)**, **고급 옵션(Advanced options)** 같은 단계가 더 나오지만
**전부 손대지 말고 넘어가시면 됩니다.**

- **Shielded instance** — 부팅 펌웨어 보호 기능. 이 프로그램과 무관하고,
  켜면 나중에 인스턴스 설정을 바꾸기 어려워집니다. **끈 상태로 두세요**
- **Confidential computing** — AMD 전용 기능이라 ARM 서버에서는 켤 수 없습니다.
  *"현재 설정으로는 켤 수 없습니다"* 라는 노란 경고가 뜨는데 **오류가 아니라 안내**이니
  무시하고 넘어가시면 됩니다

> 이 서버에서 실제로 챙겨야 할 보안은 ① 관리자 비밀번호 변경,
> ② 3단계 수신 규칙을 회사 공인 IP 로 제한, ③ 나중에 HTTPS 적용 —
> 이 세 가지이고, 위 토글들과는 무관합니다.

만들어지면 인스턴스 화면의 **공용 IP 주소**를 적어 둡니다. (예: `152.70.xxx.xxx`)

## 3단계 · 접속 포트 열기 (오라클 콘솔)

> 이 단계를 빼먹으면 설치를 다 하고도 접속이 안 됩니다. **가장 많이 걸리는 부분입니다.**

콘솔에서 **네트워킹 → 가상 클라우드 네트워크 → (VCN 선택) → 서브넷 → (서브넷 선택) → 보안 목록 → 기본 보안 목록**

**수신 규칙 추가** 를 누르고 아래처럼 입력합니다.

| 항목 | 값 |
| --- | --- |
| 소스 유형 | CIDR |
| 소스 CIDR | `0.0.0.0/0` |
| IP 프로토콜 | TCP |
| 대상 포트 범위 | `8000` |

> 회사에서만 접속하게 하려면 `0.0.0.0/0` 대신 **회사 공인 IP 대역**을 넣으세요.
> 훨씬 안전합니다. 회사 공인 IP 는 사무실에서 <https://ifconfig.me> 에 접속하면 확인됩니다.

## 4단계 · 서버가 회수되지 않게 하기

오라클은 **7일간 CPU·네트워크·메모리 사용률이 모두 20% 미만**인 무료 서버를 회수합니다.
자산관리처럼 가끔 쓰는 시스템은 여기에 걸리기 쉽습니다.

콘솔 우측 상단 **결제 및 비용 관리 → 업그레이드 → 종량제(Pay As You Go)로 업그레이드**

종량제로 바꾸면 **회수 대상에서 제외되고, 무료 한도 안에서는 계속 0원**입니다.
다만 무료 한도를 넘기면 과금되니, **결제 및 비용 관리 → 예산**에서
한도 1달러짜리 알림을 하나 걸어 두시는 걸 권합니다.

## 5단계 · 설치

내려받은 SSH 키로 서버에 접속합니다. (`<공용IP>` 는 2단계에서 적어 둔 주소)

**macOS / 리눅스 · 윈도우 PowerShell**

```bash
chmod 600 ~/Downloads/ssh-key-*.key          # 윈도우는 이 줄 생략
ssh -i ~/Downloads/ssh-key-*.key ubuntu@<공용IP>
```

접속되면 아래를 그대로 붙여넣습니다.

```bash
sudo apt-get update && sudo apt-get install -y git
git clone https://github.com/youj971104-star/GNN.git
cd GNN
git checkout claude/it-asset-management-program-76s19u
sudo bash deploy/oracle-setup.sh
```

스크립트가 Docker 설치, 서버 방화벽 열기, 서비스 기동까지 알아서 합니다.
처음엔 **5분 정도** 걸립니다. 끝나면 접속 주소와 관리자 비밀번호가 화면에 표시됩니다.

```
   접속 주소 : http://152.70.xxx.xxx:8000

   아이디    : admin
   비밀번호  : (자동 생성된 값)
```

## 6단계 · 확인

브라우저에서 위 주소로 접속해 로그인하고, **우측 상단 '비밀번호 변경'에서 비밀번호를 바꾸세요.**

둘러보기용 샘플 데이터를 넣고 싶으면:

```bash
./deploy.sh demo
```

실제로 쓰실 땐 샘플을 지우고 시작하세요.

```bash
docker compose down -v && ./deploy.sh start
```

## 접속이 안 될 때

먼저 서버에서 진단 명령을 돌려 보세요.

```bash
./deploy.sh doctor
```

| 증상 | 확인할 것 |
| --- | --- |
| 서버에서는 되는데 밖에서 안 됨 | **3단계 수신 규칙**을 안 열었을 가능성이 가장 큽니다 |
| 수신 규칙을 열었는데도 안 됨 | 서버 안쪽 iptables 문제입니다. `sudo bash deploy/oracle-setup.sh` 를 다시 실행하면 열어 줍니다 |
| 재부팅 후 다시 안 됨 | 방화벽 규칙이 저장되지 않은 경우입니다. 위와 같이 다시 실행하세요 |
| 주소를 모르겠다 | 오라클 콘솔의 인스턴스 화면에 있는 **공용 IP 주소** 입니다 |

## 평소 운영

```bash
cd ~/GNN
./deploy.sh status      # 상태 확인
./deploy.sh logs        # 로그 보기
./deploy.sh backup      # 백업 (backups/ 폴더에 저장)
./deploy.sh update      # 최신 코드로 업데이트
```

**백업은 꼭 챙기세요.** 무료 서버는 회수되거나 사라질 수 있습니다.
서버 안에만 두지 말고, 주기적으로 본인 PC 로 내려받아 보관하시길 권합니다.

```bash
# 본인 PC 에서 실행 — 서버의 백업 파일을 가져온다
scp -i ~/Downloads/ssh-key-*.key ubuntu@<공용IP>:~/GNN/backups/*.db ./
```

매일 새벽 3시 자동 백업을 걸려면 서버에서:

```bash
(crontab -l 2>/dev/null; echo "0 3 * * * cd ~/GNN && ./deploy.sh backup") | crontab -
```
