# 게임 페이지 설명 (복사해서 붙여넣기)

크리에이터 허브 → 내 게임 → 기본 정보(또는 세부 정보)에서 이름과 설명 칸에 붙여넣으세요.
설명은 1,000자 이하입니다. 영어 버전은 **현지화**(Localization) 메뉴에서 영어 번역으로 등록하면 해외 이용자에게 영어로 보입니다.

## 🇰🇷 한국어

**이름:** 🧊 얼음땡 술래잡기

**설명:**
```
🧊 얼음! 🔥 땡! 친구들과 함께하는 얼음땡 술래잡기!

🔴 술래는 도망자를 얼려요
🔵 도망자는 도망치면서 얼어 있는 친구를 만져 녹여 줘요
⏱️ 2분 동안 한 명이라도 살아남으면 도망자 승리!

✨ 특징
• 라운드마다 경기장 지형이 새로 바뀌어요 — 같은 판은 없어요!
• 버티기, 친구 구하기, 얼리기로 코인 획득
• 코인으로 눈송이·오로라·용암 트레일 구매
• 승리, 얼린 횟수, 구해 준 횟수 기록

👫 2명 이상 모이면 시작해요. 친구를 초대해서 같이 놀아요!
👍 재밌었다면 좋아요와 즐겨찾기 부탁해요!
```
