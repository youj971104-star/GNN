# 🧊 얼음땡 술래잡기 (Freeze Tag) — 기획서

## 1. 한 줄 소개
한국 전통 놀이 **얼음땡**을 로블록스 라운드 게임으로. 술래에게 닿으면 얼고, 친구가 와서 만지면 녹는다. 2분 동안 한 명이라도 살아남으면 도망자 승리!

## 2. 왜 이 장르인가
| 근거 | 설명 |
|---|---|
| 친구랑 하는 게임 | 로블록스 이용자는 친구와 같이 들어오는 비율이 높음 → 파티형 라운드 게임은 **바이럴(친구 초대)** 에 강함 |
| 규칙이 모두에게 익숙 | 술래잡기는 전 세계 공통. "녹여 주기" 규칙이 협동을 만들어 일반 술래잡기와 차별화 |
| 매판 새 지형 | 라운드마다 장애물 배치를 코드가 새로 만듦 → 같은 판이 없음 |
| 짧은 라운드 | 2분 + 대기 15초 → "한 판만 더" 루프, 모바일에 적합 |

## 3. 타깃 연령층
- **핵심: 8~14세**. 놀이터/학교에서 하던 놀이를 그대로 온라인에서.
- 공격·피 표현 없음(얼음 효과만) → 성숙도 **Minimal**.
- 혼자보다 **친구와 함께** 오는 유저가 핵심 → 비공개 서버(Private Server) 판매를 켜 두세요 (게임 설정 → Access → Private Servers, 월 구독형 수익).

## 4. 라운드 흐름
1. **대기 (15초)** — 2명 이상 모이면 카운트다운. 로비에서 상점 이용.
2. **역할 배정** — 4명당 술래 1명. 술래는 빨간 테두리, 5초 동안 묶였다가 출발. 술래 속도 18 / 도망자 16.
3. **경기 (120초)**
   - 술래 근처(5스터드)에 가면 도망자는 **얼음**(얼음 블록에 갇힘)
   - 얼은 친구를 다른 도망자가 만지면 **땡**(해동). 얼고 3초 후부터 녹일 수 있음
   - 도망자 전원이 얼면 술래 승리, 시간이 끝나면 도망자 승리
4. **보상** — 참가 5, 생존 10초마다 2, 구출 15, 얼리기 10, 승리 30 코인 → 트레일 구매
