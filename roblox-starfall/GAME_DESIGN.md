# ⭐ 별똥별 타이쿤 (Starfall Tycoon) — 기획서

## 1. 한 줄 소개
밤하늘에서 떨어지는 별을 주워 팔고, 자석·가방·행운을 키우고, 별 요정 펫을 모아 **환생**으로 점점 더 큰 숫자를 만드는 수집형 시뮬레이터.

## 2. 왜 이 장르인가
| 근거 | 설명 |
|---|---|
| 검증된 장르 | 로블록스 매출 상위권은 시뮬레이터/타이쿤/펫 수집(성장 + 수집 + 숫자 커지는 재미)이 꾸준히 차지 |
| 1인 개발 적합 | 3D 모델·애니메이션 없이 **코드 + 기본 파트(네온 구)** 만으로 완성도 있는 화면 가능 |
| 수익화 친화 | "더 빨리, 더 많이" 욕구 → 게임패스·부스트가 자연스럽게 팔림 (강제 결제 없이도) |
| 짧은 세션 | 5분만 해도 업그레이드 1~2개 → 모바일 유저(로블록스 이용자 다수)에게 맞음 |
| 차별점 | 땅에 박힌 광물을 '때리는' 일반 시뮬레이터와 달리, **하늘에서 떨어지는 별을 쫓아다니는** 움직임 + 희귀 별이 떨어질 때 빛·알림 연출 |

## 3. 타깃 연령층
- **핵심: 9~14세** (초등 고학년~중1). 숫자 성장, 펫 수집, 친구에게 자랑(리더보드·공지)에 가장 반응이 큰 층.
- **보조: 15~17세** — 환생/은하 알 등 장기 목표로 붙잡음.
- 콘텐츠: 폭력·공포 요소 없음 → 로블록스 **성숙도(Maturity) 질문지에서 "Minimal" 등급** 목표 → 노출 범위가 가장 넓음.
- UI 는 글자를 최소화하고 이모지·색으로 의미 전달 (어린 유저 + 해외 유저 대응). 이후 영어 번역 추가 권장 (로블록스 자동 번역 + 직접 번역표).

> ⚠️ 13세 미만 이용자가 많기 때문에 "**결제를 해야만 진행되는**" 설계(페이월)는 피했습니다. 모든 것은 무료로도 도달 가능하고, 결제는 **속도/편의/자랑** 만 삽니다. 로블록스 정책·부모 신뢰·장기 평점 모두에 유리합니다.

## 4. 핵심 루프
```
별 줍기(자석 범위) → 가방 가득 → 판매 발판 → 코인
      ↑                                     ↓
  환생(영구 배율 +0.5)  ←  업그레이드 / 펫 뽑기
```
- **업그레이드 4종**: 자석 범위 · 가방 크기 · 별 소환 속도 · 행운
- **별 등급 5종**: 일반(1) · 희귀(6) · 영웅(30) · 전설(180) · 우주(1500)
- **펫(별 요정) 7종 / 알 3종**: 장착 시 코인 배율 증가. 기본 3칸
- **환생**: 코인·업그레이드 초기화, 코인 배율 영구 증가. 비용 5천 × 4^환생횟수
- **출석 7일 연속 보상**, 서버 공지(전설 펫/환생/유성우) → 사회적 자극

## 5. 수익 모델 (Robux)
로블록스 개발자 수익은 크게 3가지입니다: **게임패스**, **개발자 상품(소모품)**, **프리미엄 페이아웃**(프리미엄 회원 체류 시간 비례, 자동).

### 5-1. 게임패스 (한 번 사면 영구)
| 상품 | 가격 | 효과 | 노리는 심리 |
|---|---|---|---|
| 코인 2배 | 199 R$ | 판매 코인 x2 | 가장 잘 팔리는 정석 상품 |
| 자동 판매 | 149 R$ | 가방이 차면 자동 판매 + "지금 판매" 버튼 | 귀찮음 제거 |
| 행운의 부적 | 249 R$ | 행운 x2 | 희귀 별 연출 보고 싶은 욕구 |
| VIP | 399 R$ | 코인 +25%, 가방 +50%, 채팅 [VIP] 태그 | 자랑 + 혜택 묶음 (고가 앵커) |
| 펫 슬롯 +2 | 99 R$ | 장착 3→5칸 | 첫 구매 유도용 저가 상품 |

### 5-2. 개발자 상품 (여러 번 구매)
| 상품 | 가격 | 효과 |
|---|---|---|
| ☄️ 유성우 소환 | 99 R$ | **서버 전체** 2분간 별 3배 + 행운 x2, 구매자 이름 공지 → 다른 유저도 이득이라 "영웅" 심리, 반복 구매율 높음 |
| 🍀 행운 물약 | 39 R$ | 15분 행운 x3 (시간 누적) |
| 코인 꾸러미 / 금고 | 49 / 199 R$ | **현재 진행도에 비례한 양** (다음 환생 비용의 20% / 120%) → 언제 사도 쓸모 있음 |

### 5-3. 프리미엄 페이아웃
- 프리미엄 회원에게 코인 +10% → 프리미엄 유저 체류 시간 ↑ → 자동 수익 ↑

### 5-4. 확률형 아이템 규정 대응 (중요)
- 알(뽑기)은 **게임 코인으로만** 구매하지만, 코인을 Robux 로 살 수 있으므로 로블록스 정책상 "유료 확률형 아이템"에 해당할 수 있음.
- 그래서 **알 확률을 UI 에 항상 공개** (한국 게임산업법 확률 표시 의무에도 대응).
- `PolicyService` 로 확률형 아이템이 제한된 국가 유저에게는 **코인 판매 상품을 숨김**.

### 5-5. 기대 수익 감 잡기 (가정치)
- 로블록스 일반적인 지표 감각: 결제 유저 비율 1~3%, 결제 유저 평균 150~400 R$/월.
- 예) 동시 접속 200명 수준(일 사용자 약 5천 명) → 월 활성 3만 명 × 2% × 250 R$ ≈ **월 15만 R$**
- DevEx 환전율 약 0.0038 USD/R$ → 약 **570 USD/월** + 프리미엄 페이아웃.
- 숫자는 전부 가정입니다. 실제는 **유입(광고·추천 알고리즘)** 이 결정합니다. 출시 후 대시보드의 D1/D7 리텐션, 평균 플레이 시간, ARPDAU 를 보고 조정하세요.

## 6. 출시 & 성장 전략
1. **소프트 런치**: 친구/디스코드로 20~50명 테스트 → 밸런스(`Config.luau`) 조정
2. **추천 알고리즘 지표**: 로블록스는 플레이 시간·재방문·평점을 봄 → 출석 보상, 유성우 공지가 이를 위한 장치
3. **스폰서 광고(Ads Manager)**: 하루 소액부터, 썸네일/아이콘 A/B 테스트가 클릭률을 가장 크게 바꿈
4. **업데이트 주기**: 2주마다 새 알/새 섬 → "UPDATE" 태그로 재유입
5. **틱톡/유튜브 쇼츠**: "우주 별 뽑았다" 같은 짧은 영상
