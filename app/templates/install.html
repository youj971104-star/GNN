갤럭시 · 안드로이드

크롬 (권장)

  1. 크롬으로 이 사이트에 접속해 로그인합니다.
  2. 오른쪽 위 ⋮ 메뉴 → 홈 화면에 추가 (또는 앱 설치)
  3. 설치를 누르면 홈 화면에 자산관리 아이콘이 생깁니다.

삼성 인터넷

  1. 삼성 인터넷으로 접속해 로그인합니다.
  2. 주소창의 설치 아이콘(↓)을 누르거나, 아래쪽 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면

로그인은 설치할 때 쓴 브라우저와 함께 기억됩니다. 앱 안의 QR 스캔 메뉴로 라벨을 찍으면 다시 로그인할 일이 없습니다. 폰 기본 카메라로 찍을 때도 같은 브라우저로 열리게 하려면 설정 → 애플리케이션 → 기본 앱 선택 → 브라우저 앱을 설치한 브라우저로 맞춰 두세요.

아이폰

  1. 사파리로 이 사이트에 접속합니다. (크롬 앱에서는 설치가 안 될 수 있습니다)
  2. 아래쪽 공유 버튼(□↑) → 홈 화면에 추가 → 추가
  3. 홈 화면의 자산관리 아이콘으로 열고, 처음 한 번 로그인합니다.

아이폰은 앱과 사파리가 로그인을 따로 기억해서, 앱에서 한 번 더 로그인해야 합니다.

설치하면

  • 홈 화면 아이콘으로 바로 열리고, 주소창 없이 화면을 넓게 씁니다.
  • 아이콘을 길게 누르면 QR 스캔·자산 관리로 바로 갈 수 있습니다. (안드로이드)
  • 내용은 언제나 서버의 최신 정보입니다. 프로그램이 바뀌어도 앱을 다시 설치할 필요가 없습니다.
  • 인터넷이 끊기면 안내 화면이 나옵니다. 연결 없이 보거나 입력할 수는 없습니다.
