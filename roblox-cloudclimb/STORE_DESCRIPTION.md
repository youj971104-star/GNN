# 게임 페이지 설명 (복사해서 붙여넣기)

크리에이터 허브 → 내 게임 → 기본 정보(또는 세부 정보)에서 이름과 설명 칸에 붙여넣으세요.
설명은 1,000자 이하입니다. 영어 버전은 **현지화**(Localization) 메뉴에서 영어 번역으로 등록하면 해외 이용자에게 영어로 보입니다.

## 🇰🇷 한국어

**이름:** ☁️ 구름 오비 [100 스테이지]

**설명:**
```
☁️ 하늘 끝까지 올라가는 100단계 오비!

구름 위로 이어진 100개의 스테이지를 지나 🏆 정상에 도착해 보세요.
10단계마다 새로운 구역이 나와요: 초록 들판 → 솜사탕 구름 → 무지개 다리 → … → 우주 끝!

🎮 이런 장애물이 있어요
• 점프 발판, 좁은 다리, 사다리
• 🔥 빨간 용암 줄, 빙글빙글 회전 막대
• 움직이는 발판, 밟으면 사라지는 유리 발판

✨ 특징
• 체크포인트 자동 저장! 다시 들어와도 그 자리부터
• ◀ ▶ 스테이지 선택기로 깬 곳은 언제든 다시 가기 (친구 도와주기!)
• 스테이지를 깰 때마다 코인 → 멋진 트레일 구매
• 정상에 오르면 환생! 코인 배율이 영원히 올라가요

👍 재밌었다면 좋아요와 즐겨찾기 부탁해요!
```

## 🇺🇸 English

**Name:** ☁️ Cloud Climb Obby [100 Stages]

**Description:**
```
☁️ Climb 100 stages all the way to the sky!

Jump across 100 stages floating above the clouds and reach the 🏆 summit.
A new zone every 10 stages: Green Fields → Cotton Candy Clouds → Rainbow Bridge → … → Edge of Space!

🎮 Obstacles
• Jump pads, narrow beams, trusses
• 🔥 Lava strips and spinning bars
• Moving platforms and vanishing glass tiles

✨ Features
• Checkpoints save automatically — come back anytime
• ◀ ▶ Stage selector to revisit cleared stages (help your friends!)
• Earn coins for every new stage and unlock cool trails
• Reach the top and Rebirth for a permanent coin boost

👍 Like and favorite if you had fun!
```
