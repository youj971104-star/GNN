# ☁️ 구름 오비 (Cloud Climb Obby) — 기획서

## 1. 한 줄 소개
하늘로 이어진 **100개 스테이지**를 점프·회전 막대·사라지는 발판을 피해 정상까지 오르는 오비(장애물 코스) 게임.

## 2. 왜 오비인가
| 근거 | 설명 |
|---|---|
| 로블록스에서 가장 큰 장르 중 하나 | 규칙 설명이 필요 없음 → 처음 온 아이도 3초 만에 이해 |
| 제작비 최저 | 기본 파트만으로 완성. 코스는 **코드가 자동 생성** (Seed 숫자만 바꾸면 새 코스) |
| 검증된 수익 모델 | "스테이지 건너뛰기" 상품은 오비 장르의 대표 매출원 |
| 스트리머/쇼츠 친화 | "100단계 깨기 도전", "넘어진 횟수" → 영상 소재 |

## 3. 타깃 연령층
- **핵심: 7~12세** (초등학생). 오비는 로블록스에서 가장 어린 층이 많이 하는 장르.
- 폭력 없음, 채팅 외 상호작용 최소 → 성숙도 **Minimal**.
- 글자 대신 색으로 신호: **빨강 = 위험**, 반투명 = 사라짐, 흰 네온 = 체크포인트.
- **뽑기(확률형 아이템) 없음** → 부모·정책 측면에서 가장 안전한 구조.

## 4. 게임 구조
- 스테이지 1~100 + 🏆 정상. 10단계마다 테마 구역(들판 → 솜사탕 구름 → … → 우주 끝).
- 난이도 곡선: 스테이지가 오를수록 발판이 작아지고 간격이 넓어지며, 새 장애물이 차례로 등장
  - 1~: 점프 발판, 좁은 다리 · 4~: 사다리 · 6~: 용암 줄 · 12~: 회전 막대 · 16~: 움직이는 발판 · 22~: 사라지는 발판
- 체크포인트는 자동 저장 → 다시 접속하면 가장 높은 스테이지부터.
- **스테이지 선택기(◀ ▶)**: 깬 스테이지는 무료로 자유 이동 (친구 도와주러 가기).
- **환생**: 정상 도착 후 1단계로 돌아가는 대신 코인 배율 영구 +0.5, 리더보드에 환생 수 표시.
- 코인 → 트레일(꾸미기) 구매. 확률 없음, 가격 공개.

## 5. 수익 모델
| 종류 | 상품 | 가격 | 메모 |
|---|---|---|---|
| 개발자 상품 | ⏭️ 스테이지 건너뛰기 | 19 R$ | **주력 매출.** 화면 오른쪽에 항상 보이는 버튼 |
| 개발자 상품 | ⏩ 5단계 건너뛰기 | 79 R$ | 묶음 할인 효과 (19×5=95 대비) |
| 개발자 상품 | 💰 코인 500 | 39 R$ | 트레일 구매용 |
| 게임패스 | ⚡ 스피드 | 99 R$ | 이동 16 → 22 |
| 게임패스 | 🦘 점프 업 | 149 R$ | 점프 +30% (어려운 구간이 쉬워짐 → 높은 구매 동기) |
| 게임패스 | 💰 코인 2배 | 99 R$ | |
| 게임패스 | 👑 VIP | 249 R$ | 황금 트레일 + 채팅 태그 + 코인 +50% |
| 자동 | 프리미엄 페이아웃 | — | 프리미엄 회원 코인 +20% |

- **좌절 지점 = 구매 지점**: 어려운 장애물(회전 막대·사라지는 발판)이 등장하는 12·16·22 단계 근처에서 건너뛰기 구매가 집중됩니다. 너무 어려우면 이탈하므로, 출시 후 "스테이지별 이탈률"을 보고 `Config.luau` 난이도를 조정하세요.
- 오비는 결제 단가가 낮은 대신 **유입이 많음**. 썸네일에 "100 STAGES" 처럼 숫자를 크게 넣으면 클릭률이 좋습니다.
