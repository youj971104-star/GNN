# 🍢 떡볶이 가게 타이쿤 — 기획서

## 1. 한 줄 소개
빈 땅에서 시작해 **떡볶이 솥 → 어묵 → 순대 → 튀김 → 김밥 → 라면 기계**까지, 버튼을 밟아 분식집을 키우는 타이쿤. 음식이 컨베이어를 타고 계산대로 가면 돈이 쌓인다.

## 2. 왜 이 장르인가
| 근거 | 설명 |
|---|---|
| 타이쿤은 로블록스 스테디셀러 | "버튼 밟기 → 건물이 짠! 생김"이라는 즉각적인 보상 |
| **K-푸드 테마** | 떡볶이·김밥·라면은 해외 아이들에게도 인기 → 한국 테마 자체가 차별점, 영어 번역 시 "Korean Street Food Tycoon" |
| 저장되는 타이쿤 | 많은 타이쿤이 나가면 초기화되지만, 이 게임은 **건물이 저장**되고 다시 들어오면 자동으로 지어짐 |
| 오프라인 수입 | 접속 안 한 동안에도 벌어 둠 → 매일 들어올 이유 (리텐션) |

## 3. 타깃 연령층
- **핵심: 9~15세**. 경영/수집 욕구 + 꾸미기.
- 폭력 없음 → 성숙도 **Minimal**. 뽑기 없음.
- 부모 세대도 아는 소재라 "가족 같이 하기" 영상 소재로도 좋음.

## 4. 게임 구조
- 서버당 가게 터 6개, 들어오면 자동 배정.
- 버튼 17개 (순서대로 열림)
  - **음식 기계 6종**: 음식(블록)을 컨베이어에 떨어뜨림
  - **토핑 2종**: 지나가는 음식 가치 ×1.5, ×2
  - **인테리어 8종**: 간판, 테이블, 줄무늬 지붕, 네온, 배달 오토바이, 황금 간판 → 수입 +%
- 계산대 노란 발판을 밟아 수금 (자동 수금 패스 있으면 바로 지갑으로)
- **프랜차이즈(환생)**: 모두 지으면 가게 초기화 + 수입 배율 영구 +0.5 → "2호점, 3호점…"
- 오프라인 수입: 기본 최대 2시간, 25% 속도
